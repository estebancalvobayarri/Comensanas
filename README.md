# Comensanas

Web de Comensanas, la consulta de nutrición de Ruth Rodrigo en Valencia y Llíria.

Es una web estática de una sola página, sin dependencias ni proceso de compilación:

- `index.html` — contenido y estructura
- `styles.css` — estilos (adaptados a móvil)

## Ver en local

Abre `index.html` en el navegador.

## Publicar

Puede publicarse tal cual en GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) o en cualquier hosting estático, y apuntar el dominio comensanas.es hacia él.
